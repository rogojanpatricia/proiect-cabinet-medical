# Proiect: Aplicatie pentru evidenta si gestiunea unui cabinet medical pentru un medic de familie

## Autor
* Patricia Rogojan 
* Discipline: Proiectarea Bazelor de Date / Proiectarea Software

## Scopul Proiectului
Scopul aplicatiei este sa centralizeze istoricul medical al pacientilor intr-un singur loc, ajutand medicul de familie sa ia decizii rapide si sa reduca birocratia pentru a castiga mai mult timp pentru consultatii.
